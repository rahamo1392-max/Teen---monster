TEEN MONSTER — راهنمای راه‌اندازی
==================================

داخل این بسته:
- index.html: اپ اصلی
- manifest.json و icon.svg: نصب روی صفحه اصلی
- sw.js: کش اولیه برای باز شدن سریع‌تر
- supabase-schema.sql: جدول‌ها، احراز هویت و قوانین امنیتی اولیه

۱) اجرای آزمایشی
- فایل ZIP را از حالت فشرده خارج کن.
- برای تست ساده، index.html را باز کن. بخش‌های اعضا، انتخاب آهنگ و پیش‌نمایش گالری در حالت محلی کار می‌کنند.
- ثبت‌نام واقعی، خبر عمومی و چت مشترک تا تنظیم Supabase فعال نمی‌شوند.
- برای نصب PWA باید سایت با HTTPS منتشر شود؛ باز کردن فایل به‌صورت file:// برای نصب کافی نیست.

۲) ساخت بک‌اند آنلاین رایگان با Supabase
- در supabase.com یک پروژه بساز.
- از Project Settings / API یا Connect، Project URL و publishable/anon key را بردار.
- فایل index.html را ویرایش کن و این دو مقدار را جایگزین کن:
  SUPABASE_URL
  SUPABASE_ANON_KEY
- فقط کلید publishable/anon را در فرانت‌اند بگذار؛ هرگز service_role/secret key را منتشر نکن.
- در SQL Editor، محتوای supabase-schema.sql را اجرا کن.
- در Authentication تنظیمات تأیید ایمیل را بررسی کن.
- پس از ثبت‌نام با حساب خودت، UUID آن را از Authentication > Users کپی کن؛ خط UPDATE انتهای SQL را با UUID واقعی تکمیل و اجرا کن تا نقش مدیر بگیرد.
- در Database > Replication / Realtime، جدول public.messages را برای Realtime فعال کن.

۳) انتشار رایگان روی Netlify
- سایت را از طریق GitHub به Netlify وصل کن یا پوشه‌ی پروژه را در پنل Netlify منتشر کن.
- مطمئن شو index.html، manifest.json، sw.js و icon.svg همگی در ریشه‌ی سایت هستند.
- پس از انتشار با HTTPS، لینک را در Safari آیفون/آیپد یا Chrome اندروید باز کن.
- iPhone/iPad: Share > Add to Home Screen.
- Android/Chrome: منوی سه‌نقطه > Install app یا Add to Home screen.

۴) تبدیل به اپ فروشگاهی
این پروژه در حال حاضر PWA است، نه فایل آماده‌ی IPA یا APK. برای انتشار در App Store / Google Play باید آن را با ابزارهایی مانند Capacitor در محیط توسعه مناسب بسته‌بندی، امضا و آزمایش کنی؛ برای iOS معمولاً به macOS و Xcode نیاز است.

۵) محدودیت‌های نسخه‌ی اولیه
- پروفایل‌های اعضا فعلاً نمونه هستند و نام‌ها را می‌توان در آرایه‌ی members در index.html ویرایش کرد.
- افزودن آهنگ و عکس/ویدئو فعلاً محلی است؛ فایل‌ها برای دیگر کاربران آپلود نمی‌شوند.
- چت آنلاین و اخبار از Supabase استفاده می‌کنند؛ کد پایه‌ی چت نیاز به آزمایش نهایی پس از تنظیم پروژه دارد.
- برای گالری و آپلود عمومی رسانه، باید Storage bucket و قوانین دسترسی جداگانه طراحی شوند.
- در انتشار عمومی، برای کاربران کم‌سن اطلاعات شخصی را محدود کن، امکان گزارش/حذف پیام داشته باش و قبل از باز کردن چت عمومی قوانین رفتاری روشن بگذار.
